Lua API & browser compatibility

Define setup() and loop(). Pixels are zero-based. Call luxio_set_pixel_color(index, red, green, blue, white, warm_white, cool_white), with channels from 0 to 255. Unavailable channels must be zero. luxio_get_pixel_count() returns the controller count; luxio_millis() returns animation time. Brightness belongs to the system.
Studio uses local HTTP requests. Your browser may request local-network permission or block HTTPS-to-HTTP access. Cross-browser compatibility still requires validation; a successful simulation does not confirm device connectivity.
